# 关键帧检查清单

每轮关键帧和成片都逐条过。这份清单是用来自查的，不是用来给自己打分的；最终评判交给用户。

## 禁用套路（用户已经否掉的东西）

- 文字当画面主角（把字烧进木头、隧道门框里放字）。
- 隧道、粒子、光晕之类的万能特效。
- 一块黑底加辉光糊弄过去，没有环境。
- 抽象意象代替具体主体。
- AI 生图/生视频、图片素材。

## 画面

- [ ] 主体（实物、界面、过程或场景）一眼认得出，并且占画面主要面积（横屏定格全景时大约占画面宽度的 60% 以上）。
- [ ] 画幅是 1920×1080 横屏。
- [ ] 屏幕类画面不刺眼，没有大面积亮白；屏幕里的内容铺满屏幕，不缩在一角。
- [ ] 有和故事相关的环境，不是空背景。
- [ ] 没有炸白的高光块；屏幕上的字读得清。
- [ ] 阴影柔和，把漂浮的部件/图层和环境联系起来。
- [ ] 细节密度够：放大到原尺寸看，芯片丝印、元件、排线都在。
- [ ] 没有品牌 logo 或商标图形。

## 文字与标注

- [ ] 标题没有压在亮面上；开场特写时只有小字幕。
- [ ] 每个标注指向的东西此刻真的看得见，并且指对了。
- [ ] 标签之间不重叠，不压在主体或亮面上，不超出画面。
- [ ] 文案是简体中文，事实准确（日期、参数、型号查过）。

## 动画（成片联系表）

- [ ] 从头到尾没有剪切和淡入淡出，镜头运动连续。
- [ ] 开场 3 秒内能看到当年的真实数据（钩子）。
- [ ] 揭示动作（拆开、拆层、展开）看得懂，没有穿模，也没有东西凭空出现。
- [ ] 没有物体长时间挡住镜头。
- [ ] 文件小于 30 MB。

## 交付时向用户说明

镜头节拍、用了哪些真实数据、自己已经看到的瑕疵（具体到秒）、渲染耗时，以及是否跑在 GPU 上。
